# SEMANTIC_MEMORY.md — What You Know

Durable knowledge about the user and the world. The framework rewrites
this file between sessions via consolidation — you read it, you don't
edit it.

Principles:
- One section per topic (a person, a preference, a recurring concept).
- Only durable facts. Transient state ("they said hi today") does not
  belong here — that's what EPISODIC is for.
- No timestamps in this file. This file is "what is true now," not
  "how my understanding evolved."

Suggested shape:

## Index
A one-line entry per topic section, for scanning.

## <Topic>
Bullets. Tag with type when useful:
- *fact* — stable truth (include *why* when non-obvious).
- *preference* — something the user prefers, with the reason if known.
- *correction* — something the user pushed back on; don't repeat it.
